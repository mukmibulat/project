# Проект с использованием разных алгоритмов на основе датасета Amazon Sales.


**1.1** В проекте на данный момент реализована работа с данными о продажах Amazon sales с использованием Python, FastApi и HTML.

- **HashMap** —  быстрый поиск заказа по его `OrderID`.
- **Segment Tree** — подсчёт общей суммы `Quantity` за выбранный диапазон записей и обновление количества для отдельной записи.
- **FastAPI** — API для работы с реализованными структурами данных.
- **HTML-интерфейс** — простейшая страница, через которую можно выполнять поиск заказа, считать сумму и изменять количество.

Данные загружаются из файла Amazon.csv(**100 000 строк и 20 столбцов**).

**1.2** В проект был добавлен алгоритм PageRank для определения наиболее значимых товаров на основе связей между покупателями и товарами. Для этого был построен двудольный граф, в котором связи учитывают количество купленных товаров. Реализован отдельный модуль `pagerank.py` и API-метод, возвращающий топ-10 товаров по рейтингу. Также добавлено отображение результатов в HTML-интерфейсе.
